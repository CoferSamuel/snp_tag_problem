\chapter{Matrices de Significancia Estadística}\label{anexo:significancia_abs}

Este anexo recopila las matrices de significancia estadística correspondientes al test \textit{post-hoc} de Dunn-Holm ($p < 0.05$) aplicado sobre los resultados del experimento de objetivos absolutos. Estas representaciones gráficas ilustran las diferencias estadísticas significativas entre todas las combinaciones de algoritmo, inicialización y cruce evaluadas para las métricas principales.
